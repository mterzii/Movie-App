# Movie-App
A web application to explore popular movies and TV shows, built with vanilla JavaScript and powered by the TMDB API.

## Features
- Search movies and TV shows
- View detailed information (overview, rating, release date)
- Trending / Popular lists
- Responsive UI
- Powered by the TMDB API
